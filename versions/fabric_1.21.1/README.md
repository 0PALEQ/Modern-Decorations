# Modern Decorations

Modern Decorations is a Fabric mod for Minecraft 1.21.1. It adds 263 modern
furniture and decoration blocks, functional storage furniture, refrigerator and
oven inventories, a creative-mode tab, and stonecutter recipes for every block.

## Requirements

- Minecraft 1.21.1
- Fabric Loader 0.19.3 or newer
- Fabric API 0.116.13+1.21.1
- Java 21

## Building

The project uses Fabric Loom and official Mojang mappings.

```powershell
./gradlew.bat clean build
```

The distributable mod is written to `build/libs/mdm-26.9-fabric-1.21.1.jar`.
