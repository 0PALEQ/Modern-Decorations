# Modern Decorations

Modern Decorations is a Fabric mod for Minecraft 26.3. It adds 263 modern
furniture and decoration blocks, functional storage furniture, refrigerator and
oven inventories, a creative-mode tab, and stonecutter recipes for every block.

## Requirements

- Minecraft 26.3
- Fabric Loader 0.19.5 or newer
- Fabric API 0.162.0+26.3
- Java 25

## Building

The project uses Fabric Loom with Minecraft's unobfuscated 26.3 classes.

```powershell
./gradlew.bat clean build
```

The distributable mod is written to `build/libs/mdm-26.10-fabric-26.3.jar`.
