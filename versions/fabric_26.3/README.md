# Modern Decorations

Modern Decorations is a Fabric mod for Minecraft 26.2. It adds 263 modern
furniture and decoration blocks, functional storage furniture, refrigerator and
oven inventories, a creative-mode tab, and stonecutter recipes for every block.

## Requirements

- Minecraft 26.2
- Fabric Loader 0.19.3 or newer
- Fabric API 0.154.2+26.2
- Java 25

## Building

The project uses Fabric Loom with Minecraft's unobfuscated 26.2 classes.

```powershell
./gradlew.bat clean build
```

The distributable mod is written to `build/libs/mdm-26.9-fabric-26.2.jar`.
