# Modern Decorations

Modern Decorations is a NeoForge mod for Minecraft 1.21.11. It adds 263 modern
furniture and decoration blocks, functional storage furniture, refrigerator and
oven inventories, a creative-mode tab, and stonecutter recipes for every block.

## Requirements

- Minecraft 1.21.11
- NeoForge 21.11.42 or newer for Minecraft 1.21.11
- Java 21

## Building

The project uses NeoForge ModDevGradle and official Mojang/Parchment mappings.

```powershell
./gradlew.bat clean build
```

The distributable mod is written to `build/libs/mdm-26.9-neoforge-1.21.11.jar`.
