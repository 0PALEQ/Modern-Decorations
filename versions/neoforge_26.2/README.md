# Modern Decorations

Modern Decorations is a NeoForge mod for Minecraft 26.1.2. It adds 263 modern
furniture and decoration blocks, functional storage furniture, refrigerator and
oven inventories, a creative-mode tab, and stonecutter recipes for every block.

## Requirements

- Minecraft 26.1.2
- NeoForge 26.1.2.78 or newer
- Java 25

## Building

The project uses NeoForge ModDevGradle with Minecraft's unobfuscated 26.1.2 classes.

```powershell
./gradlew.bat clean build
```

The distributable mod is written to `build/libs/mdm-26.9-neoforge-26.1.2.jar`.
